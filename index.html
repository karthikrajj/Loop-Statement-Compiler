C Loop Compiler Architecture & Integration

Overview for students, educators, and compiler team members

1. Compiler Pipeline Stages

1. Lexical Analysis

Scans C source code character-by-character to tokenize keywords (for, while, do), identifiers, numeric constants, strings, operators, and delimiters.

2. Syntax Parsing

Implements a Recursive Descent parser verifying C grammar rules, loop parenthesization, clause sequencing, and nested block matching.

3. AST Construction

Builds a hierarchical tree representing Program → Function → Loop → Condition → Loop Body statements.

4. Semantic Checks

Detects assignment inside condition (i = 5 vs i == 5), empty conditions, and infinite loop patterns.

2. How to Connect Your Real C Compiler

This web interface is designed with a plug-and-play adapter layer (compiler_adapter.py):

  1. Place your compiler source code in compiler/compiler.c.
  2. Compile the executable: 
    cd compiler
clang -std=c99 -O2 compiler.c -o compiler.exe
# Or with GCC:
gcc -std=c99 -O2 compiler.c -o compiler.exe
# Or run:
build.bat
  3. The Flask backend automatically detects compiler/compiler.exe and immediately activates Real C Compiler Mode!
  4. If the binary is absent, the backend falls back to Demo Mode, clearly marked with warning badges so you never confuse simulated output with real compilation.
